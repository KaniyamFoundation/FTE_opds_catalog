# FreeTamilEbooks OPDS Catalog

Official OPDS (Open Publication Distribution System) catalog for [FreeTamilEbooks.com](https://freetamilebooks.com), hosted via GitHub Pages at **[catalog.freetamilebooks.com](https://catalog.freetamilebooks.com)**.

## Catalog Feeds

- **Website / Landing Page**: [https://catalog.freetamilebooks.com](https://catalog.freetamilebooks.com)
- **OPDS Root (Categories)**: [https://catalog.freetamilebooks.com/index.xml](https://catalog.freetamilebooks.com/index.xml)
- **All Books Feed**: [https://catalog.freetamilebooks.com/books.opds.xml](https://catalog.freetamilebooks.com/books.opds.xml)
- **Metadata (JSON)**: [https://catalog.freetamilebooks.com/books.json](https://catalog.freetamilebooks.com/books.json)

## How to use in OPDS Readers

Compatible with **KOReader, FBReader, Moon+ Reader, Librera Reader, Cantook (Aldiko), Thorium Reader, Apple Books (via OPDS)**:

1. Open your reader app and go to **Catalogs** / **OPDS**.
2. Tap **Add Catalog / Custom Feed**.
3. Set Catalog Name: `Free Tamil Ebooks`
4. Set Feed URL: `https://catalog.freetamilebooks.com/index.xml` (or `https://catalog.freetamilebooks.com`)
5. Save and browse books directly by category!
